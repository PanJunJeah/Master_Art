# 面试速答卡（考前 10 分钟看这一页）

## 一、五个数字

| 数字 | 含义 |
|---|---|
| **5** | Agent 工具数：查知识、查作品、查展览、草稿、订阅 |
| **6** | 单轮工具调用上限（`agent.max-tool-steps`） |
| **30** | 草稿有效期（分钟），不占库存 |
| **2.5s** | RAG 检索超时（毫秒），超时降级 |
| **10** | 业务表数量 |

## 二、30 秒项目陈述

> 我做过两个全栈项目，代表项目是 Master Art 在线艺术品展览平台：10 张表、20+ 页面，独立完成前后端。亮点是接入 DeepSeek 做策展 Agent，5 个工具能查作品、查余票、生成预约草稿，但**真实扣库存的接口永远不注册成工具**，必须用户人工确认——这条边界我用白名单测试守着。另一个是智慧点餐平台，重点是订单状态机、金额精度和幂等。

## 三、架构一句话

> Spring Boot 3.4 + JPA + MySQL 做后端，Vue3 + Element Plus + Pinia 做前端；Agent 层是 ChatClient + 5 个 `@Tool` + 步数守卫 + 可替换的 RAG 检索器；工具本质是 Service 的薄封装，所以权限和事务只有一套。

## 四、Function Calling 六步（背）

1. 请求带 messages + tools(JSON Schema)
2. 模型返回 `finish_reason=tool_calls` + 工具名/参数
3. 应用执行本地方法
4. 追加 assistant(tool_calls) + tool(结果) 两条消息
5. 再请求模型
6. 模型继续调工具或输出最终回答，直到 `stop`

> 一句话：**模型只提议，执行权在应用侧。**

## 五、三层防线

| 层 | 手段 | 作用 |
|---|---|---|
| 能力面 | 真实写入方法没有 `@Tool` | 模型看不见，也就调不到 |
| 编排面 | 未知工具 → 异常 → 收敛为拒绝话术 | 零写入 |
| 数据面 | 唯一约束 + 条件 UPDATE + 状态守卫 | 重复/超卖/越权在 DB 层被挡 |

## 六、两个"一句话正确性"

- **防超卖**：`UPDATE ... SET sold = sold + n WHERE total - sold >= n`，判断和扣减在同一条语句，用影响行数判成败。
- **幂等**：服务端用 `SHA-256(userId|exhibitionId|sessionId|ticketCount)` 定义规范键，先查后建 + 唯一约束兜底；模型只能复用键，不能自造。

## 九、十个高频问题的一句话答案

1. **为什么不用向量库？** 语料几百条、要可解释可回归；检索器抽了接口，升级路径是全文索引→向量→混合+rerank。
2. **RAG 怎么解决整句召回不到？** 按标点切词 + 中文二元组，多词元分别召回后去重合并。
3. **超时怎么办？** Future.get 2.5s，超时抛专用异常，工具层降级为友好提示，不让模型编。
4. **为什么 6 步？** 最长链路 5 步，留 1 步余量；再多大概率在打转，烧 token。
5. **记忆怎么隔离？** `MessageWindowChatMemory(20)` + conversationId=`user-{id}`。
6. **SSE 为什么不用 EventSource？** 只支持 GET、不能带 header/body；用 fetch + ReadableStream，按 `\n\n` 切包。
7. **为什么不用 WebSocket？** 单向推送、一问一答，SSE 更简单且天然支持重连。
8. **AI 怎么测？** 脚本化 OpenAI 端点，真框架真循环，5 个场景 + 白名单反射测试。
9. **怎么防 prompt injection？** 没有危险工具 + 系统提示 + 人工确认 + 工具轨迹可审计。
10. **项目不足？** 认证链路（JWT 校验/BCrypt）、RAG 语义能力、可观测性。

## 十、五个必须能讲的"真实细节"

1. 整句 `LIKE` 召回不到 → 分词 + 二元组修复。
2. 工具参数带 userId → 模型拿不到 ToolContext → 改服务端注入。
3. `@Tool` 依赖 `-parameters` 编译参数，否则参数名变 `arg0`。
4. 兜底查询用 `LEFT JOIN FETCH`，避免事务外懒加载异常。
5. 唯一约束冲突要 catch `DataIntegrityViolationException` 后回查重放。
